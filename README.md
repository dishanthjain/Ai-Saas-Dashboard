# NOVA AI Workspace

NOVA is a unified AI workspace for productivity, featuring chat, image generation, code generation, text summarization, and email/blog composition.

## Tech Stack
- Frontend: React, Vite, Tailwind CSS, TypeScript
- Backend: Node.js, Express, MongoDB

## Development
1. `npm install` in root.
2. `cd server && npm install`.
3. Create `.env` files from `.env.example`.
4. `npm run dev` to start everything.
